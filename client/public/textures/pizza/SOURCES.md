# Pizza 3D photo textures: sources

All source assets are **CC0** (public domain, commercial use OK, no attribution required).
Raw downloads are not in the repo; only these small derived WebP files are.

| File | Source | Licence | How it was made |
|---|---|---|---|
| `cheese-detail.webp` | ambientCG **Pizza002** (1K-JPG), https://ambientcg.com/view?id=Pizza002 | CC0 (https://docs.ambientcg.com/license/) | 196 px leaf-free crop of baked mozzarella, leaves removed, separable offset-blend to tile, stored as a colour ratio (128 = x1) at 512 px |
| `board-map.webp`, `board-normal.webp`, `board-orm.webp` | Poly Haven **kitchen_wood** (1k), https://polyhaven.com/a/kitchen_wood | CC0 (https://polyhaven.com/license) | diffuse / normal (GL) re-encoded to WebP; roughness packed into G of an ORM map (R = 1, no AO), 512 px |
